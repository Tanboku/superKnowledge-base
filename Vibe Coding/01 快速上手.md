# 01 快速上手

> 零基础 10 分钟做出第一个网页应用并部署上线。

## 准备工作

- 一台能上网的电脑 + 浏览器
- 一个 AI 应用生成平台账号（免费额度即可）
- 一个 GitHub 账号（用于保存代码和部署）

**新手工具选择**：推荐从在线零代码平台起步（如 Bolt.new、Lovable、美团 NoCode、百度秒哒），无需安装任何软件，浏览器里对话生成项目、实时预览、一键发布。国内访问不畅时可换用国产平台。等熟练后再进阶到 Cursor 等专业编辑器。

## 选第一个项目

标准：简单但完整、有实际用处、能看到效果。适合新手的三类：

1. 个人名片网页 —— 最快获得成就感
2. 待办事项应用（Todo List）—— 功能完整、体验完整开发流程
3. 倒计时网页（考试 / 生日）—— 有创意、视觉效果好

## 三轮对话出成品

**第 1 轮：描述基本需求**。需求分三块写清楚：

```text
请帮我做一个待办事项应用网页，要求：
1. 功能需求：添加任务、复选框标记完成（完成显示删除线）、删除任务、显示完成/未完成数量
2. 界面要求：简洁现代、清新蓝色调、圆角、阴影、手机端响应式
3. 技术要求：HTML + CSS + JavaScript，数据存浏览器本地存储
```

**第 2 轮：优化细节**。看到初版后再提具体调整：占位符文字、按钮文案、标题、背景渐变、「清空已完成」按钮等。每次 1~5 个要求，改完看效果再继续。

**第 3 轮：加新功能**。任务优先级（高/中/低配色）、编辑任务、清空确认、空列表友好提示等。

## 验证与上线

- 逐项测试功能；用预览窗口的设备切换检查手机端效果
- 多数在线平台支持一键发布（Deploy），得到公开访问链接
- 通用方案：把代码推到 GitHub，用 Vercel 等平台一键部署静态/全栈项目，免费额度够个人使用

## 理解你做的东西

- 让 AI 解释项目结构：每个文件是干什么的
- 看不懂的代码直接贴回去问「这段是做什么的」
- 尝试小修改（改文案、改颜色）观察效果，是最低成本的学习方式

## 对话要点

1. 需求要具体：「背景改成蓝色渐变、按钮加圆角」优于「做得好看点」
2. 一次别改太多：小步快跑，每轮 1~5 个点
3. 有 Bug 直接说：告诉 AI 哪里不对，附上报错信息
4. 不懂就问：要求 AI 解释代码
