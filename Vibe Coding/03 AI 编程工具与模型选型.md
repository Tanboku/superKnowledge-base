# 03 AI 编程工具与模型选型

> 工具四大类、三大主流、模型怎么选。

## 工具四大类

| 类型 | 代表 | 适合 |
|------|------|------|
| AI 零代码平台 | Bolt.new、Lovable、美团 NoCode、百度秒哒 | 零基础入门、快速原型 |
| AI 代码编辑器 | Cursor、Codex、Trae | 日常开发主力，可视化编辑与审查 |
| AI 命令行工具（CLI Agent） | Claude Code、OpenCode | 复杂任务、长程自主开发 |
| IDE 插件 | GitHub Copilot、通义灵码 | 在现有 IDE 里增强 |

## 三大主流工具

- **Cursor**：基于 VS Code 的 AI 编辑器，界面友好、可一键切换主流模型，新手首选
- **Codex**（OpenAI）：有桌面端和 CLI，默认 GPT 系列模型，订阅性价比高
- **Claude Code**：终端 Agent，复杂任务处理能力最强（SWE-bench 顶级），命令行门槛略高，建议熟练后再上

## 工具层面要学什么（五件事）

1. 基本使用：Chat 对话、Agent 自主编程、Tab 补全、`@` 引用上下文
2. 核心特性：Plan Mode 计划模式、Background Agent 后台执行、Browser Use 浏览器测试
3. 扩展增强：**MCP**（给 AI 装「万能插头」连外部服务：读设计稿、查数据库、联网搜索）、**Agent Skills**（给 AI 装技能包：文档处理、代码规范）
4. 使用技巧：多 Agent 并行、子 Agent 拆分任务
5. 自定义配置：规则文件（`AGENTS.md` / `CLAUDE.md` / `.cursorrules`）定义 AI 行为规范

## 模型怎么选

两个维度：**预算** 和 **场景**。模型迭代极快，具体型号排名以近期评测为准，下面是相对稳定的结构性结论。

### 按预算

- 预算充足：订阅制（编辑器 / 模型官方会员约 20 美元档）用顶级模型，复杂项目和商业项目首选
- 预算有限：国产模型 API 按量计费很便宜（约为国际模型的 1/10），配合各家免费额度，学习和个人项目完全够用

### 按场景

| 场景 | 建议 |
|------|------|
| 学习阶段 | 便宜好用的国产模型 + 免费额度，重点是熟悉工作方式 |
| 前端 / UI | 前端审美是顶级模型的强项，尽量用第一梯队 |
| 全栈项目 | 编码能力强的全能模型 |
| 大型代码库 | 注意上下文窗口（1M token 级），部分模型超长输入会加价 |
| 快速迭代 | 输出速度快、首字延迟低的模型 |
| 让 AI 自己验收前端效果 | 选**原生多模态**（能看图）的模型，纯文本模型看不见自己写的页面 |
| 大量测试调用 | 用最便宜的 API，可把批量任务挪到空闲时段（部分厂商峰谷计费） |

### 国际 vs 国产

- 国际模型：最复杂任务上仍是天花板，工具生态最丰富
- 国产模型（DeepSeek、通义千问、GLM、Kimi 等）：便宜、中文理解好、国内直连快；原生多模态正成为标配，选型时留意「支不支持视觉」
- 结论：**没有最好的模型，只有最适合当前需求的模型**，按任务灵活切换
